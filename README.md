##  Project Title

Polynomial Calculator Using Linked List in C++

##  Problem Statement

To develop a menu-driven polynomial calculator using a linked list in C++ that performs polynomial addition, subtraction, and multiplication while combining terms with equal exponents and displaying the simplified results.

##  Project Description

The Polynomial Calculator is a menu-driven application developed using C++ to perform mathematical operations on polynomial expressions. The project uses a singly linked list to store polynomial terms dynamically. Each node contains a coefficient, an exponent, and a pointer to the next node.

The system accepts two polynomial expressions from the user and allows them to perform addition, subtraction, and multiplication. It automatically combines terms having equal exponents and removes terms whose coefficients become zero. The program displays the results in a simplified mathematical format.

The application also includes input validation, dynamic memory allocation, and memory management. This project demonstrates the practical use of linked lists and object-oriented programming concepts in solving mathematical problems.

##  Objectives

1. To implement a polynomial using a singly linked list.
2. To perform addition, subtraction, and multiplication of polynomials.
3. To combine terms having the same exponent.
4. To display polynomial expressions in simplified form.
5. To understand dynamic memory allocation and linked-list operations.
6. To apply object-oriented programming concepts in C++.

##  Hardware and Software Requirements

- Hardware: Computer or laptop, minimum 4 GB RAM.
- Software: Windows/Linux operating system, C++ compiler, VS Code or Code::Blocks.

##  Applications

1. Mathematical calculations involving polynomial expressions.
2. Learning and demonstrating linked-list data structures.
3. Understanding dynamic memory allocation in C++.
4. Practicing object-oriented programming concepts.
5. Educational use in data structures and algorithms.

## Conclusion

The Polynomial Calculator successfully demonstrates polynomial operations using a linked list in C++. It provides a simple and user-friendly way to perform addition, subtraction, and multiplication while maintaining polynomial terms in simplified form. The project helps develop practical knowledge of data structures, pointers, and memory management.
